# Changelog

All notable changes to the LocalConnect project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-05-01

### Added
- User authentication flow with role-based authorization for customers and workers.
- Service search and worker profile browsing.
- Slot booking system with overlap validation and duplicate request prevention.
- Booking lifecycle management (Pending, Confirmed, Completed, Cancelled, Expired).
- Worker review and rating aggregation system.
